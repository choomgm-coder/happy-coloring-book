# Happy Coloring Book

A responsive, green-themed coloring book catalogue built with Next.js 15, TypeScript, Tailwind CSS, and the App Router.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). To deploy, import this repository in Vercel; its Next.js settings are detected automatically.

Set `NEXT_PUBLIC_MESSENGER_URL` in Vercel if you want the chat button to link to a specific Facebook Messenger conversation.
